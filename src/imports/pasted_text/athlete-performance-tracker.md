Общая задача
Создай современное веб-приложение уровня профессионального спортивного ПО для тренеров по легкой атлетике (в первую очередь многоборье), которое позволит полностью вести спортсменов: хранить историю результатов, проводить тестирования, анализировать прогресс, планировать тренировки и получать детальную аналитику.
Интерфейс должен выглядеть дорого и современно.
Стиль:
минимализм
спортивная эстетика
темная тема + светлая
плавные анимации
glassmorphism
современные графики
красивый dashboard
адаптивность
высокая скорость работы
